Syntax help

Constituency: labelled brackets, e.g. [S [NP This] [VP [V is] [NP/\ a wug]]]. Type several bracketed clauses one after another to draw them all (stacked or side by side). A trailing /\ on a label draws a triangle.

Sub/superscript: _ and ^ are shown as plain characters. To get a subscript type _\ before the text (DP_\1), for a superscript type ^\ (X^\2). It lasts until the next space or bracket. Use \[ and \] for literal brackets.

Movement arrows: give exactly two nodes the same subscript ([DP_\1 What] … [DP t_\1]) and an arrow is drawn from the later one to the earlier one.

Leipzig glossing: put a gloss in angle brackets after a word or label, with no spaces: [V° sees<see.3SG.PRS>], [nsubj:she<3SG.F.NOM>]. Terminals show the gloss beneath them and other nodes beside them, with grammatical abbreviations (all capitals) in small caps. Use . to join meanings, - and = for morpheme and clitic boundaries (e.g. dog-PL, see.PST). Common abbreviations: 1/2/3 person, SG, PL, NOM, ACC, GEN, DAT, ERG, ABS, PST, PRS, FUT, PFV, IPFV, NEG, DEF, INDF, M, F, N, INF, PASS, COP. It can sit alongside {semantic} labels: V<see.PST>{agent}.

Leipzig glosses: write semantic labels as glosses, e.g. eat-PST, dog.PL, 1SG.NOM, DEF. Lowercase = lexical meaning (English word), UPPERCASE = grammatical abbreviation (shown in small caps); - . = separate parts. Use the chips in the node editor to add common abbreviations.

Editing: click any node (or a dependency relation) in the drawing to edit its label, semantic label and relation, add a child below, a sibling beside, or a parent above, or delete it. The text box updates to match. Semantic labels are written NP{agent} in the text.

Dependency tree: brackets with relation:word, the head first: [ate [nsubj:John] [dobj:apple [det:an]]]. A table (below) also works.

Drag & drop: drag a tree node onto another to move it there as a child. In the arc diagram, drag from a head word to its dependent to set the head (hold Shift to add an extra, enhanced head). Click a word or relation label to edit it. Ctrl/Cmd+Z and Ctrl/Cmd+Y undo and redo.

Enhanced / extra heads: in the head column write 2|4:xsubj (primary head, then extra heads with relations); they are drawn dashed and crossing arcs are allowed. Columns are word head rel POS gloss lemma (use _ to skip). In bracket dependency trees write rel:word/POS/lemma.

Import / export: paste or import Penn Treebank, LaTeX qtree/forest or CoNLL-U and it is converted. Export text gives Penn, qtree, forest, DOT or CoNLL-U. Trees can be saved in your browser by name.

Dependency model: one token per line, word head relation [POS], head is the 1-based index of the head word, 0 for the root. CoNLL-U is also accepted.
